# K.M. GRAND – Luxury Gateway

## 🌐 Live Demo
https://kmgrand-luxury-gateway.lovable.app/

## 📌 Project Overview
K.M. GRAND is a premium luxury restaurant and hospitality website developed using HTML, CSS, and JavaScript. The website showcases luxury dining, room booking, banquet hall services, and restaurant information with a modern and responsive design.

## ✨ Features
- Luxury homepage
- Responsive design
- Room booking section
- Restaurant showcase
- Banquet hall information
- Contact section
- Modern UI/UX

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
